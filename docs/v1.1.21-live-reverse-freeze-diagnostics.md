## Model Package Change

The inference package now emits identity diagnostics for each selected match and diagnostic row:

- `identityConfidence`
- `identityDiagnostics.policy`
- `identityDiagnostics.weakVisualIdentity`
- `identityDiagnostics.ambiguousVisualIdentity`
- `identityDiagnostics.candidateSetLikelyMissingVisualMatch`
- `identityDiagnostics.runnerActionHint`

When visual identity is weak or ambiguous, match confidence and global assignment diagnostics are capped rather than reporting high confidence for a best-of-bad candidate.
